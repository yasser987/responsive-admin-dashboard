# Responsive Admin Dashboard

A responsive, multi-page admin dashboard interface built with HTML and CSS. The project presents dashboards, settings, profiles, projects, courses, friends, files, and subscription plans in a consistent UI.

## Highlights

- Responsive layouts for desktop, tablet, and mobile screens
- Reusable CSS utility classes and shared design tokens
- Dashboard cards, progress indicators, tables, forms, and navigation
- Multiple connected pages with a consistent visual system
- Keyboard-visible focus states and accessible form labels
- Font Awesome icons and locally bundled web fonts

## Pages

- Dashboard
- Settings
- Profile
- Projects
- Courses
- Friends
- Files
- Plans

## Built With

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive media queries
- Font Awesome
